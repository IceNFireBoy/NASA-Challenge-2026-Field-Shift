# SI (AI) use disclosure: Has Bean Planned

This document discloses how Synthetic Intelligence (SI) tools were used in the NASA Space Apps 2026 project "Has Bean Planned" by team NASApusomo. It is written to meet the Space Apps requirement to label SI use.

## Tools used and what for

| Tool | Used for |
|---|---|
| **Claude (claude.ai)**, by Anthropic | Research, drafting of the core data pipeline and the calculation engine, and drafting of the first documentation |
| **Claude Code**, by Anthropic | Building the user interface, pipeline extensions (Giovanni CSV reader, MODIS NDVI and SoilGrids fetch), and documentation  |
| **Gemini**, by Google | An early literature summary. Used only as a pointer to primary sources. Values that first came through it have since been checked by the team against primary sources (crop durations and seed rates against the DA mungbean guide and a 1998 peanut report; nitrogen fixation against Rosales et al., 1998). |
| **Image or video tools** | None. The app uses emoji and hand-made SVG only |

## What SI produced, stated plainly

- **Code:** half of the source code was drafted by SI, the rest were debugged and checked by SI, and reviewed and tested by the team.
- **Text:** interface wording, the why-card text, the glossary and these documents were drafted by SI and reviewed by the team.
- **Filipino labels:** drafted by SI in `frontend/src/lib/i18n.js` and `frontend/src/lib/lang.jsx`.
- **Modelling choices proposed by SI and adopted by the team.** These are not data. Each is shown in the app with an **Assumption** badge:
  - Farmer-view priority weights (a picked priority gets 40, the others 5).
  - Farmer-view traffic-light cut-offs (water 80% and 50% of need met; soil tier 70 and 40; income above, at or below zero; work at 75% and 100% of the labour limit).
  - Growth-stage proportions, starting soil water fractions, soil-health and forage tiers, labour figures marked as assumptions, irrigation efficiency, and the Monte Carlo ranges.
- **Illustrative values:** corn yield, production cost and seed rate, peanut yield and the pumping cost are placeholders, badged **Illustrative**, and editable in the app. Crop prices and the mungbean and peanut production costs are no longer placeholders: they are PSA figures looked up by a team member.

## What SI did not produce

- **No climate, satellite or soil number was generated by SI.** They come from the files listed below, fetched from the named services.
- **No statistic on screen is an SI estimate.** Scores, rankings and the what-if shares are computed by the tested engine from the data file, the parameter file and user input.
- **SI does not make the recommendation.** The ranking is a rule-based calculation that a person can read and check.
- **Original ideation and implementation was not done by SI.** The team proposed the idea which was only given implementation suggestions by SI.

## Where the numbers come from

| Data | Source | How it reached the app |
|---|---|---|
| Rainfall the model runs on | NASA GPM IMERG Final, monthly, V07 (GPM_3IMERGM), doi:10.5067/GPM/IMERG/3B-MONTH/07 | NASA Giovanni area-averaged time series, downloaded by a team member and committed as `pipeline/data/imerg_giovanni.csv` |
| Temperature, root-zone soil wetness, comparison rainfall | NASA POWER daily point API | `pipeline/fetch_climate.py` |
| Vegetation greenness (NDVI) | NASA MODIS MOD13Q1 v061, doi:10.5067/MODIS/MOD13Q1.061 | ORNL DAAC subsetting service, `pipeline/fetch_extras.py` |
| Soil texture hint | ISRIC SoilGrids 2.0 (CC BY 4.0) | SoilGrids REST API, `pipeline/fetch_extras.py` |
| El Niño and La Niña labels | NOAA CPC Oceanic Niño Index, ERSSTv6 table | Values copied from the NOAA table into the pipeline and checked against the page |
| Crop coefficients, root depths, available soil water | FAO Irrigation and Drainage Paper 56 | `frontend/src/engine/params.js`, badged **Sourced** |
| Yield response to water | FAO Irrigation and Drainage Paper 33 (values as given in Paper 66) | `params.js`, badged **Sourced** |
| Local yields, prices and context | DOST-PCAARRD (2018), PSA OpenSTAT (farmgate prices for Region II, January to May 2026; legume costs and returns, 2021; tables downloaded by a team member, saved in `pipeline/data/psa/`), PhilRice Isabela (2021), Philippine Daily Inquirer (2026) | `params.js` and `content.js`, badged by status |
| Base map | OpenStreetMap contributors | Tiles loaded in the browser |

Every number on screen is traceable to the climate data file, the parameter file or user input, and every economic and agronomic input carries a status badge.
