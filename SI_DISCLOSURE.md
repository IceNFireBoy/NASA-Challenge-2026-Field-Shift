# SI (AI) use disclosure: Has Bean Planned

This document discloses how Synthetic Intelligence (SI) tools were used in the NASA Space Apps 2026 project "Has Bean Planned" by team NASApusomo. It is written to meet the Space Apps requirement to label SI use.

## Tools used and what for

| Tool | Used for |
|---|---|
| **Claude (claude.ai)**, by Anthropic | Research and checking of sources, drafting of the core data pipeline and the calculation engine, and drafting of the first documentation |
| **Claude Code**, by Anthropic | Building the user interface (Farmer view and the Analytics and Community view), charts and map, pipeline extensions (Giovanni CSV reader, MODIS NDVI and SoilGrids fetch), a source and link check, documentation and deployment |
| **Gemini**, by Google | An early literature summary (the "team PDF"). Used only as a pointer to primary sources. Values that came through it are badged **Secondary source** in the app. One of them, nitrogen fixed by mungbean (21 to 85 kg N/ha), was checked against the primary record (Rosales et al., 1998, OSTI ETDEWEB 634524). The others (mungbean and peanut crop duration, peanut harvest labour) have not been checked against their primary sources and remain badged as secondary |
| **Image or video tools** | None. The app uses emoji and hand-made SVG only |

## What SI produced, stated plainly

- **Code:** almost all source code was drafted by SI and reviewed and tested by the team.
- **Text:** interface wording, the why-card text, the glossary and these documents were drafted by SI and reviewed by the team.
- **Filipino labels:** drafted by SI in `frontend/src/lib/i18n.js` and `frontend/src/lib/lang.jsx`. They need, and are getting, a native-speaker review.
- **Modelling choices proposed by SI and adopted by the team.** These are not data. Each is shown in the app with an **Assumption** badge:
  - Farmer-view priority weights (a picked priority gets 40, the others 5).
  - Farmer-view traffic-light cut-offs (water 80% and 50% of need met; soil tier 70 and 40; income above, at or below zero; work at 75% and 100% of the labour limit).
  - Growth-stage proportions, starting soil water fractions, soil-health and forage tiers, labour figures marked as assumptions, irrigation efficiency, and the Monte Carlo ranges.
- **Illustrative values:** production costs, some yields and prices, seed rates and the pumping cost are placeholders, badged **Illustrative**, and editable in the app.

## What SI did not produce

- **No climate, satellite or soil number was generated by SI.** They come from the files listed below, fetched from the named services.
- **No statistic on screen is an SI estimate.** Scores, rankings and the what-if shares are computed by the tested engine from the data file, the parameter file and user input.
- **SI does not make the recommendation.** The ranking is a rule-based calculation that a person can read and check.

## Where the numbers come from

| Data | Source | How it reached the app |

Every number on screen is traceable to the climate data file, the parameter file or user input, and every economic and agronomic input carries a status badge.

## Source check on 15 November 2026

Near the deadline the team had Claude Code open every cited link and compare the cited figures with the pages. Result:

- **Confirmed against the source:** FAO-56 crop coefficients (mid and end season) and FAO-33 yield-response factors for beans, maize and groundnut; mungbean nitrogen fixation; San Mateo mungbean yield and area (DOST-PCAARRD); the PhilRice rice-rice-mungbean and rice-rice-corn project; the Manila Times "Munggo Capital" and idle-fields statements; the PAGASA El Niño report; the IMERG and MOD13Q1 DOIs and citations; the mungbean and peanut farmgate prices.
- **Corrected:**
  - The ENSO table was moved from NOAA's ERSSTv5 ONI to the current ERSSTv6 ONI. Two labels changed (2018-19 is now a moderate El Niño, 2024-25 is now La Niña); no scenario and no ranking changed.
  - A yellow-corn farmgate price had been attributed to a PSA figure that is actually for palay. The corn price is now badged **Illustrative** and cites only the confirmed PSA Central Luzon figure.
  - A 7,000-hectare figure had been attributed to The Manila Times; it is from DOST-PCAARRD.
  - The IMERG citation year was corrected to 2023.
- **Could not be opened by an automated client** (the sites refuse them; they open in a normal browser): PSA OpenSTAT and the PSA regional release pages. The Manila Times article is partly behind a paywall.
- **Not checked against a primary source:** the three secondary values named in the Gemini row above.

## How SI-generated content is labelled

- Every source file created with SI assistance starts with an `SI-ASSISTED` comment (`//`, `#` or `<!-- -->` as the file type requires).
- `PROGRESS.md` records the work done in each phase, including what went wrong.

## Human review and testing

- The team reviewed the generated code and documentation and directed every change.
- The calculation engine and the Farmer-view rules have automated tests (Vitest, 22 tests). The data pipeline has offline tests (pytest, 19 tests). Both suites and `npm run build` are run before each release.
- The model has not been validated against farm records.

## Limits of SI use

- SI output is treated as a draft, not as a source of facts.
- The tool supports, and does not replace, farmer and expert judgement.
